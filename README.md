# typescript-dersleri

Sıfırdan TypeScript Eğitim Serisi

Bu seride TypeScript'i en baştan, her derste tek bir konuya odaklanarak öğreniyoruz. Her dersin kodu kendi klasöründe duruyor; klasörü açıp dersle birlikte ilerleyebilirsiniz.

Seri iki bölümden oluşuyor:

* İlk bölümde TypeScript'in temellerini işliyoruz: tipler, fonksiyonlar, interface, tip daraltma.
* İkinci bölümde sınıflar, modüller, generics ve gerçek bir tarayıcı uygulamasında TypeScript kullanımına geçiyoruz.

## Nasıl çalıştırılır

```bash
npm install -g typescript
cd "ders-1 - typescript nedir"
tsc sepet.ts
node sepet.js
```

İhtiyacı olanların işine yaramasını umuyorum.
